# CLA Information

Contributors to SwayRider must accept a Contributor License Agreement (CLA) before their first contribution can be merged. There are two agreements:

| Agreement | Applies to | Template |
|-----------|------------|----------|
| **ICLA** (Individual CLA) | Individual contributors | [Individual Contributor License Agreement.odt](./CLA/Individual%20Contributor%20License%20Agreement.odt) |
| **CCLA** (Corporate CLA) | Contributions made on behalf of a company | [Corporate Contributor License Agreement.odt](./CLA/Corporate%20Contributor%20License%20Agreement.odt) |

## ICLA — Individual Contributors

- Acceptance is handled automatically via our self-hosted [cla-assistant](https://cla.hevanto-it.com) instance, using the GitHub workflow.
- Contributors are asked to sign once, before the first contribution is merged.

## CCLA — Corporate Contributors

- Manual procedure: the signing entity receives the template (see table above), signs it, and returns a signed copy, which is archived by ourselves.
- After a **CCLA** is signed, request the list of contributor GitHub usernames from the signing entity.
- Add those usernames to the **ignore** list in **cla-assistant** (cla.hevanto-it.com) so they are not asked to sign an **ICLA** — the **CCLA** already covers them.
