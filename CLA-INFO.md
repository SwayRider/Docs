# CLA Information

The **Individual Contributor License Agreements (ICLA)** are managed by [cla-assistant.io](https://cla-assistant.io)

The **Corpoare Contributor License Agreements (CCLA)** are manually signed and to be archived by ourselves.

When a **CCLA** is signed, we should request a list of contributors with the github username form the signing entity. This list of contributors should be added to the **ignore** list in **cla-assistant.io** so that they do not are asked to signe a **ICLA**. The **CCLA** covers this already.
